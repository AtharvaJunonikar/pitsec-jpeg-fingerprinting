# PITSEC JPEG Fingerprinting — Local Environment Setup

This guide walks you through setting up the project for development on your machine.

## Prerequisites

- **Python 3.8+** installed on your system
- **Git** installed and configured
- Access to the repository

## Quick Setup (5 minutes)

### 1. Clone the repository

```bash
git clone <repository-url>
cd pitsec-jpeg-fingerprinting
```

### 2. Create a virtual environment

**macOS / Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

**Windows (PowerShell):**
```powershell
python -m venv venv
venv\Scripts\Activate.ps1
```

**Windows (Command Prompt):**
```cmd
python -m venv venv
venv\Scripts\activate.bat
```

### 3. Upgrade pip and install dependencies

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Verify installation

```bash
python -c "import numpy, opencv, skimage, sklearn, jpeglib; print('✓ All packages installed successfully')"
```

## Working with the Venv

### Activating the virtual environment

Every time you work on the project, activate the venv first:

```bash
# macOS / Linux
source venv/bin/activate

# Windows
venv\Scripts\activate.bat
```

When active, your terminal prompt will show `(venv)` at the start.

### Deactivating the virtual environment

```bash
deactivate
```

### Running scripts

Once the venv is active:

```bash
python src/bulk_classify.py
python src/test_jpeg_version.py
```

## Adding New Dependencies

If you need to add a package:

1. Install it in your active venv:
   ```bash
   pip install package-name
   ```

2. Update `requirements.txt`:
   ```bash
   pip freeze > requirements.txt
   ```

3. Commit the updated `requirements.txt` to git:
   ```bash
   git add requirements.txt
   git commit -m "Add package-name to dependencies"
   ```

4. Team members can then sync by running:
   ```bash
   pip install -r requirements.txt
   ```

## Troubleshooting

### "command not found: python3"
Use `python` instead of `python3` on Windows, or ensure Python is in your PATH.

### "ModuleNotFoundError" after activating venv
1. Confirm the venv is active (look for `(venv)` in prompt)
2. Re-run: `pip install -r requirements.txt`

### jpeglib installation fails
jpeglib requires build tools. Install:
- **macOS**: `xcode-select --install`
- **Ubuntu/Debian**: `sudo apt-get install build-essential python3-dev`
- **Windows**: Use Microsoft C++ Build Tools or Visual Studio Community Edition

### OpenCV import issues
If you see errors with cv2, reinstall it:
```bash
pip uninstall opencv-python -y
pip install opencv-python
```

## Data Setup

The project expects two folders (NOT included in git, add locally):

- **`data/alaska_tif/`** — Original TIFF images from the ALASKA dataset
- **`data/compressed/`** — JPEG versions (generated by the pipeline)

Create these folders and populate them as needed for your experiments.
